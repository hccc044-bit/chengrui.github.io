Kiro远程连接插件使用

Created2026-01-05|Updated2026-01-07
|Post Views:

在使用 Kiro 进行远程 SSH 时，发现官方扩展中的微软 SSH 插件不支持 Remote 功能。推荐使用以下第三方插件替代：

插件下载

🔗 open-remote-ssh v0.0.49

安装步骤

  1. 下载 .vsix 文件
  2. 打开 Kiro，点击左侧 扩展图标
  3. 点击右上角 ⋯ → 从 VSIX 安装
  4. 选择下载的文件，完成安装即可使用

安装后即可正常通过 SSH 远程连接服务器。
