学习日志 · 2026 年 11 月

Created2026-11-01|Updated2026-11-03|学习日志
|Post Views:

11 月的主线：把存储域的 swap 收尾，正式转入「软件包与仓库」。这个月开始每个能力域配一本实操手册，随进度长。新内容在最上面，每条末尾的「能力索引」指向 RHCSA 学习地图。

2026-11-02 星期一

今天做了什么

  • 把存储域最后一块 swap 做完了（分区版全流程）：parted mkpart → partprobe → mkswap → blkid → 写 fstab → swapon -a → 验收。swapon --show 出两行，free -h 的 Swap 从 820M 变成 1.3Gi。还没重启验证，先挂着。
  • 存储手册加了实验 D（swap 分区 + swap 文件，D1–D8）；其中 swap 文件那一步只是写在纸上，本机还没做过。
  • 开了新的能力域：软件包与仓库。先弄清「仓库到底是什么」，再搭一个本地 file:// 仓库，P1–P11 走完。
  • 定下一条规矩：以后每做完一个能力域就配一本 <域>-lab.html，实验用独立小节隔开，随进度长 —— 存储的 A/B/C/D 就是模板。

卡住的地方

  • 以为「把 rpm 放进目录，dnf 就能装」。实际 dnf 只去 <baseurl>/repodata/repomd.xml 取索引，从不扫目录。故意先不跑 createrepo_c 试了一次，makecache 报 Curl error (37): Couldn't read a file:// file，正好对上。单个 rpm 走的是另一条路：dnf install ./x.rpm。
  • 以为 mount -a 会把 swap 也带上。结构上不可能：mount 需要一个挂载点，而 swap 的 fstab 第 2 字段就是 none；内核里是 mount(2) 和 swapon(2) 两条不同的系统调用。
  • .repo 里把 enabled=1 手滑写成 enable=1，dnf 照跑不误 —— 它不校验未知键，而 enabled 默认值就是 1，等于蒙对了。★ 反方向才致命：写 enable=0 想关仓库会静默无效、毫无提示。
  • grep 找 [crb] 那一段：[ 在正则里是字符类起点，必须转义。试了 grep '\$crb\$'、grep '\$crb\$' 全无匹配，最后 grep '\[crb\]' 才对；最省事的是 grep -F '[crb]'。

关键命令或配置

几条今天真正记住的判断

  • swap 有两套互不校验的身份：① 分区表里的类型标记（parted 写的，纯标签，print 的 Flags 列能看到）；② 分区开头约 4 KiB 的签名（mkswap 写，blkid 出 TYPE="swap"）。内核只认 ②，所以「Flags 里标了 swap」不能当验收。
  • swapon --show 里系统盘显示 /dev/dm-1 是内核临时编号，重启可能变 dm-2 —— fstab 绝不能写 dm-N，要写 UUID= 或 /dev/mapper/vg-lv。
  • 只写 fstab、不跑 swapon -a，重启照样生效：开机读 fstab 的不是 swapon 命令，而是 systemd-fstab-generator 把每行翻译成 .swap unit。预演的价值在于把失败挪到有人看着的时候（命令行当场报错 vs 开机静默丢/进 emergency）。
  • dnf install 那两行大小是两层：先 4.3 kB 取 repomd.xml（索引目录），确认变了才拉 44 MB 的全量元数据。所以 clean all 之后必然两行，平时只有第一行才正常。
  • --disablerepo="*" 下装 htop 报 nothing provides libhwloc.so.15，不是本地仓库坏：依赖求解只在「当前启用的仓库集合」里做，hwloc-libs 在 appstream 里被一起关掉了。这条命令只适合证明「某包来自本地仓库」。
  • 仓库跟着文件走，不跟名字走：把 rocky.repo 改名，baseos 和 appstream 一起消失，extras 还在（它住在 rocky-extras.repo）。实测 7 个 .repo 文件 → 48 个仓库定义 → 5 个启用，三个数字互不相等。
  • --enablerepo（只管这一条命令）、--set-enabled（改文件、持久）、--add-repo（写出新文件）三者别混。--set-enabled crb 之后 grep 能看到 enabled 从 0 被改成 1 —— 这就是「临时」和「持久」的实证。

下一步

  • 重启验 swap：free -h + swapon --show；若只剩 820M，先 journalctl -b | grep -i swap。
  • 软件包从 P12 接：dnf history / history undo → dnf provides → versionlock → 组与 module 流 → rpm 直接操作。

今天的配套手册

  • 存储实操手册 —— swap 已补成实验 D（D1–D8），存储域四个实验至此齐全。
  • 软件包实操手册 —— 今天 P1–P11 走的就是这一本：本地 file:// 仓库、依赖跨仓库、--set-enabled 与 --enablerepo 的区别都在里面。
  • 实操手册总览 —— 所有手册的入口和进度，以后从这里进。

能力索引 —— 今天涉及的知识点在地图上的位置：

  • 四、存储与挂载
    • swap 为什么没有 mkfs、也不 mount
    • swap 的两套身份与 dm-N 陷阱
    • 只写 fstab 不 swapon，重启会生效吗
  • 五、软件包与仓库
    • 两行大小是两层下载
    • enabled 写成 enable 为什么静默失效
    • nothing provides 与 provides 的正确写法
